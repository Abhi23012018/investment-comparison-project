# Investment Comparison Dashboard

An interactive web application that helps users compare LIC Endowment Plans, Bank Fixed Deposits (FD/RD), and Mutual Fund SIPs based on investment amount, tenure, tax bracket, and expected returns.

## Features

* Compare LIC, Bank FD/RD, and Mutual Fund SIP investments
* Calculate maturity value and after-tax returns
* Visualize results with dynamic comparison charts
* Evaluate tax-saving benefits under Section 80C
* Compare risk, liquidity, life cover, and expected returns
* Responsive and modern user interface
* Real-time calculations using JavaScript

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Financial Modeling
* Data Visualization

## Business Problem

Many investors struggle to understand the differences between traditional insurance products, fixed deposits, and mutual funds. This tool provides a side-by-side comparison to support informed financial decision-making.
